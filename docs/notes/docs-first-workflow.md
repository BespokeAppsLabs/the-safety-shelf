On the the_safety_shelf project, the Boss interrupted a `create-next-app` scaffold and redirected to "create a folder docs, and document these ideas in related .md files" instead.

**Why:** Boss wants the design captured and reviewable before any code is generated.

**How to apply:** For new features/products here, write/update the `docs/` set first and get alignment before scaffolding apps or installing deps. Don't jump straight to `create-next-app` or code gen. See [[the-safety-shelf-scope]].
